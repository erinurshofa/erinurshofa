# Siapa Saya

Saya adalah seorang Software Engineer yang membantu organisasi,
instansi, dan pelaku usaha mengubah proses kerja menjadi sistem digital
yang sederhana, mudah digunakan, dan benar-benar bermanfaat.

Saya tidak melihat diri saya sebagai orang yang sekadar menulis kode.

Saya lebih menikmati memahami bagaimana sebuah pekerjaan dilakukan,
mengapa sebuah masalah terjadi, lalu bersama pengguna merancang solusi
yang sesuai dengan kebutuhan mereka.

# Filosofi Software

Saya percaya software yang baik bukan software dengan fitur paling
banyak.

Software yang baik adalah software yang benar-benar dipakai dan membantu
pekerjaan pengguna menjadi lebih mudah.

Tidak semua proyek membutuhkan solusi yang sama.

Setiap organisasi memiliki kebutuhan, ruang lingkup, anggaran, dan
proses yang berbeda.

Salah satu proyek yang paling memengaruhi cara saya bekerja adalah
pengembangan Sistem Santunan Kematian (E‑Sankem).

Dari proyek tersebut saya belajar bahwa:

-   memahami proses bisnis jauh lebih penting daripada langsung coding;
-   pertanyaan yang tepat dapat mengurangi revisi;

layanan agar organisasi dapat mengevaluasi proses berdasarkan data
ketika hal tersebut memang relevan dengan kebutuhan proyek.
