## `> ls /proyek-pilihan`

### 🌟 01 / Featured: Catet.ai — Asisten Keuangan Berbasis AI
> Asisten pencatat transaksi keuangan pribadi dan UMKM tanpa formulir rumit—dapat diakses fleksibel melalui Web App dan Bot Telegram.

- **Masalah**: Pencatatan keuangan manual sering terbengkalai karena formulir input yang berbelit-belit dan menyita waktu.
- **Solusi**: Pengguna cukup mengirimkan **Pesan Suara (*Voice Note*)**, **Foto Struk Belanja (OCR)**, atau **Teks Santai** via Telegram / Web. AI otomatis mengekstrak nominal, dompet akun, serta kategori pengeluaran secara terstruktur.
- **Teknologi**: Next.js (App Router), TypeScript, Tailwind CSS, Telegram Bot API, Gemini / Groq API, Midtrans Gateway.
- **Tautan Langsung**: 🌐 [Live Web Demo](https://finance-ai-assistant-wine.vercel.app/) • 🤖 [Telegram Bot @CatetAibot](https://t.me/CatetAibot)

```
[Voice Note / Foto Struk / Teks Santai]
                  │
                  ▼
       [Multimodal AI Engine] ──► [Ekstraksi Data Transaksi] ──► [Dashboard & Analitik Keuangan]
```

### 🏛️ 02 / E-Sankem — Sistem Santunan Kematian Dinas Sosial
> Digitalisasi alur permohonan, verifikasi berjenjang, dan pemantauan santunan kematian warga Kota Semarang yang menghubungkan Kelurahan, Kecamatan, dan Dinas Sosial.

- **Tantangan**: Sebelumnya berkas fisik berpindah manual antarinstansi, sulit dilacak posisinya, dan memerlukan waktu proses berminggu-minggu hingga bulan.
- **Solusi**: Alur verifikasi digital terpusat, notifikasi status transparan, serta implementasi didampingi Bimbingan Teknis (Bimtek) ke seluruh operator kecamatan di Kota Semarang.
- **Dampak Nyata**:
  - Durasi layanan masa awal: **11,18 hari**
  - Durasi setelah adaptasi sistem: **3,72 hari** *(efisiensi waktu terpotong lebih dari 65%)*.
- **Akses Publik**: 🌐 [Portal E-Sankem](https://sidaksos.semarangkota.go.id/sankem)

### 🌐 03 / Website & Sistem Informasi Layanan Publik
Pengalaman digitalisasi instansi pemerintah Kota Semarang dengan fokus pada keterbukaan informasi dan kemudahan akses masyarakat:

- **[Dinas Koperasi & UMKM Kota Semarang](https://diskopumkm.semarangkota.go.id/)**: Portal resmi informasi publik dan promosi program pemberdayaan pelaku usaha.
- **[Semar Preneur Up](https://diskopumkm.semarangkota.go.id/semar-preneur-up/)**: Halaman kurasi dan inkubasi UMKM Kota Semarang.
- **[SIDAKSOS](https://sidaksos.semarangkota.go.id)**: Sistem integrasi pendataan dan intervensi program penanganan kemiskinan ekstrem (P3KE).
- **[SIPeduli](https://sosialmenyapa.semarangkota.go.id)**: Portal Sistem Informasi Pelayanan dan Perlindungan Sosial terpadu.
- **[Rumah Inspirasi Disabilitas](https://sidaksos.semarangkota.go.id/rumahinspirasi)**: Portal pendataan dan layanan inklusi bagi penyandang disabilitas.
- **[Portal Perizinan DPMPTSP](https://izin.semarangkota.go.id/)**: Portal informasi dan jalur layanan perizinan terpadu satu pintu.
- **[Dinas Sosial Kota Semarang](https://dinsos.semarangkota.go.id/)**: Website resmi profil instansi dan ragam layanan sosial.
