## `> ls /proyek-pilihan`

<details open>
<summary><h3>1. Catet.ai — Pencatat Keuangan Berbasis AI (Web & Telegram Bot)</h3></summary>

Aplikasi pencatat keuangan berbasis AI multimodal untuk mempermudah pencatatan transaksi tanpa proses input manual yang rumit. Pengguna dapat mengirimkan **Pesan Suara (*Voice Note*)**, **Foto Struk (OCR)**, atau teks santai via Telegram dan Web, lalu sistem otomatis mengekstrak nominal, dompet, dan kategori pengeluaran.

```
[Voice Note / Foto Struk / Teks] 
             │
             ▼
   [Multimodal AI Engine] ──► [Ekstraksi Data Transaksi] ──► [Sinkronisasi Dompet & Dashboard]
```

- **Teknologi**: Next.js (App Router), TypeScript, Tailwind CSS, Telegram Bot API, Gemini / Groq API, Midtrans.
- **Akses**: 🌐 [Live Demo Web](https://finance-ai-assistant-wine.vercel.app/) • 🤖 [Bot Telegram](https://t.me/CatetAibot)

</details>

<details>
<summary><h3>2. E-SANKEM — Sistem Digitalisasi Santunan Kematian</h3></summary>

Sistem digitalisasi alur permohonan, verifikasi berjenjang, dan pemantauan santunan kematian pada **Dinas Sosial Kota Semarang** yang menghubungkan Kelurahan, Kecamatan, dan Dinas Sosial.

- **Teknologi**: PHP (Yii2 Framework), MySQL, Responsive Dashboard.
- **Tantangan Awal**: Berkas manual berpindah antarinstansi dan proses memakan waktu hingga berbulan-bulan.
- **Fitur Tambahan**: Halaman analisis durasi layanan mandiri untuk mengevaluasi efisiensi waktu proses secara transparan.
- **Hasil**: Rata-rata durasi penyelesaian berkas berhasil dipangkas menjadi rata-rata **3,72 hari**.

</details>

<details>
<summary><h3>3. Sistem Informasi Layanan Publik & Aplikasi Operasional</h3></summary>

Pengembangan berbagai sistem layanan dan web operasional:

- **Portal Informasi Publik**: Website Dinas Sosial Kota Semarang, DPMPTSP, Dinas Koperasi.
- **Sistem Pendataan & Bantuan Sosial**: Pengelolaan data kesejahteraan sosial (SIDAKSOS).
- **Aplikasi Antrean & Layanan Disabilitas**: Sistem pelayanan publik terpadu.
- **Sistem POS & Inventori Kasir**: Pencatatan stok barang dan transaksi operasional usaha.

</details>
